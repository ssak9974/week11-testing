# 12주차 데이터 분석

## 데이터

- 데이터 출처: 수업에서 제공된 성적 CSV 파일
- 원본 데이터 크기: 114행, 5열
- 열 설명:
  - 학번: 학생 식별 번호
  - 이름: 학생 이름
  - 반: 학생이 속한 반
  - 과목: 시험 과목
  - 점수: 과목별 점수

## 데이터 정제

- 점수가 비어 있는 행은 분석에 사용할 수 없어 제거했다.
- 완전히 동일한 중복 행은 중복 계산을 방지하기 위해 제거했다.
- 0점 미만 또는 100점 초과 점수는 잘못된 값으로 판단해 제거했다.
- 반과 과목 이름 앞뒤의 공백을 제거했다.

## 분석 내용

pandas를 이용해 반별 평균, 과목별 평균, 반별 인원을 계산했다.

전체 평균은 1반이 높았지만, 과목별 평균은 2반이 높았다. 이는 반마다 과목별 인원 구성이 다르기 때문이다.

## 테스트

pytest로 데이터 정제 후 행 수, 반 이름 공백 제거, 그룹별 합계, 소규모 데이터의 평균을 검증했다.
